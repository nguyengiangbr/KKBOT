# Architectural Decision Records (ADRs)

## ADR 1 – Use .NET 10 LTS
*Reason*: Long‑term support, latest language features, cross‑platform.

## ADR 2 – Hexagonal Architecture
*Reason*: Enforce separation of concerns, easy testing, plugin extensibility.

## ADR 3 – FSM for workflow
*Reason*: Deterministic state transitions, clear recovery paths.

## ADR 4 – Dependency injection via Microsoft.Extensions.Hosting
*Reason*: Standard, works with all project types.
